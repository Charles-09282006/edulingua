# EduLingua

## Project Overview
EduLingua is a language learning app that helps people overcome barriers in education, work, and community life. It uses interactive lessons, conversation practice, and progress tracking to make learning personalized and motivating.

## Purpose of the System
EduLingua’s purpose is to break down language barriers by providing migrants, students, and institutions with an accessible, AI-powered learning platform. It leverages personalized lessons, real-time feedback, and interactive practice to foster inclusion, improve communication, and expand opportunities in education, employment, and community life.

## Main Key Features
1. **Personalized Dashboard:**
   - A central hub greeting the user by their name, showing their progress streaks, and offering quick access to lessons, grammar tips, and conversation practice
2. **Interactive Daily Dialogue Lessons:**
   - Real-world conversational prompts with input fields for learner responses, supported by hints and navigation buttons.
3. **Progress Tracking and Achievements:**
   - A profile page showing completed lessons, scores, progress bars, and achievement medals.
4. **Practice Conversation Mode:**
   - A dedicated feature for guided conversational practice, accessible directly from the dashboard.
5. **Customizable Settings:**
   - Options for language selection, notifications, dark mode, and account managements.
